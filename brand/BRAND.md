# George Rusu — personal brand: "Acid"

Adopted 2026-10-01. This is the brand of the person, not of the company.
FLOWENTIC has its own brand ("Signal": warm paper, ochre, round calm panels) and the two must never look alike.

## What it says

An engineer who runs real operations, direct and a little loud. Black ground, off-white type, one acid lime.
Heavy display type for claims, monospace for everything measured, soft dark panels on a faint grid.

## Colour

| Token | Value | Use |
|---|---|---|
| Ground | `#08090A` | page background |
| Panel | `#101214` / `#15181B` | cards, trace, chips |
| Ink | `#F4F4EE` | text |
| Soft | `#9EA3A8` | secondary text, mono labels |
| Line | `#23272B` / `#343A40` | hairline borders |
| **Acid lime** | `#C8FF2E` | one word in a headline, the primary button, live states |

Rules:
- One accent. Lime marks one word per headline, one primary action, and "live / needs approval" states. Never body text.
- On lime, text is always `#0A0A0A`.
- On white (CV, light theme) lime is never a text colour: it becomes a highlighter block behind black text.
- No gradients, no glow, no second accent. No ochre, no warm paper: those belong to the company.

## Type

| Voice | Family | Use |
|---|---|---|
| Display | **Archivo** 900, uppercase, tracking −0.045em, leading 0.9 | H1, H2 |
| Text | **Archivo** 400–800 | paragraphs, card titles, buttons |
| Mono | **JetBrains Mono** 400–500, uppercase labels at +0.08em | section indexes, dates, stack chips, numbers' captions, the trace |

## Shape

- Panels and cards: 18px radius, 1px hairline border, no shadow except the hero trace.
- Buttons and chips: fully round.
- Section labels: `01 / SYSTEMS` in mono, index in lime.
- Faint 56px grid behind the hero and the final block, masked to fade out.

## Signature elements

1. **The run trace** in the hero: steps of an agent run with timings; the last step waits for human approval. It shows the work instead of describing it. Always labelled as an example.
2. **The lime word**: one word per headline.
3. **"To be continued▌"**: the dashed last slot in the systems list, with a blinking cursor.
4. **Greyscale thumbnails and portrait** that turn to colour on hover.
